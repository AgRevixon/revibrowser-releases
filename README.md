# ReviBrowser releases

Installers for ReviBrowser, the browser platform for agencies by Revixon. Download from https://www.revixon.com/revibrowser/ (always the current verified build) or from the Releases tab here. Every installer has a .sha256 and a .sig (Ed25519, public key in the revibrowser-desktop repository). No account is needed to download; you sign in with your Revixon ID inside the app.
